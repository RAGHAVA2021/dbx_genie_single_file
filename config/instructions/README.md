# General instructions

`general_instructions.md` contains only global behaviour that cannot be represented through the single structured data source, column metadata, SQL snippets, or example SQL. It follows the canonical Genie instruction headings and stays below the documented 2,000-character guidance. `text_instruction_justification.md` records why free-text instruction is needed, its risk, and how it will be validated; it is documentation and is not injected into the Agent.
